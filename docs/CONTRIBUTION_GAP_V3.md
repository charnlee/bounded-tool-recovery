## 有限而可检验的主张

1. 原始四种表示是组合干预。新增相同面板格式和字节长度的对照，依然不能完全排除 tokenization、措辞、重复和注意力影响；不把它命名为纯计算消融。
2. 状态正确、执行历史正确、声明发生、声明当时正确、声明有充分公开证据是不同评价层次。新指标不追溯替代原来主指标，而是透明追加。
3. 预算改变可能改变策略比较，不能将确认预算造成的差距解释为任务恢复优势。规则也应能使用逐项时钟和已知依赖语义。
4. 核心数据与诊断均来自相同已知任务语法和单个 API 模型。零重复事件不能支持降低重复副作用；规则全部成功不能证明一般工具任务不需要模型。

本轮先完成指标、规则、表示三个诊断。如果核心结论仅剩受控评价建议，就收窄论文，不通过大范围追加数据制造优势。若要声称实践可迁移，下一轮需在独立状态型工具环境给出对应干预；当前合成依赖任务不得改名为真实外部验证。该项仍是外部有效性的限制，不在本轮“已解决”清单中。
